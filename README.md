# Sigma Terminal

## Financial Analytics & Decision-Support Platform

Sigma Terminal is an interactive financial analytics platform built with **Python and Streamlit**. It combines portfolio analysis, quantitative optimization, risk modeling, stress testing, and macroeconomic analysis into a single dashboard.

I built Sigma Terminal to apply **finance, economics, and data analysis** concepts to real-world financial data and turn that data into clear, decision-useful insights.

---

## 📊 Overview

Sigma Terminal brings together three core areas of financial analysis:

### 💼 Portfolio Analysis

- Track portfolio value, returns, and profit/loss
- Analyze asset allocation and portfolio weights
- Compare performance against market benchmarks
- Evaluate historical portfolio performance
- Analyze correlations between portfolio assets

### 📈 Risk & Portfolio Optimization

- Maximum Sharpe portfolio optimization
- Minimum-variance portfolio optimization
- **5,000-portfolio Monte Carlo simulation**
- Efficient-frontier modeling
- Maximum drawdown analysis
- 30-day rolling annualized volatility
- Portfolio stress testing
- Scenario-based market shocks

### 🌎 Macroeconomic Analysis

- Consumer Price Index (CPI)
- Year-over-year inflation
- Real GDP growth
- Federal Funds Rate
- Unemployment and labor-market trends
- 2-Year and 10-Year Treasury yields
- 10Y–2Y Treasury spread
- Economic regime analysis

## 💡 Financial Analysis & Decision Support

Sigma Terminal is designed to go beyond displaying financial data by transforming it into useful analytical outputs.

The platform can:

I built Sigma Terminal to develop practical experience applying **financial analysis, economics, quantitative modeling, and programming** to real financial data.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR-REPOSITORY-URL
cd OptiQuant-Terminal
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Launch Sigma Terminal

```bash
python -m streamlit run app.py
```
